The yard is the list

Each container is drawn as a shipping container: 20′ or 40′ by its memory limit, grouped into bays by stack. The crane follows your selection.

Dependencies, drawn live

The Map lays containers out by dependency depth. Solid lines come from depends_on; dotted orange lines are connections Shipyard sees in each container's /proc/net/tcp but that nobody declared.

IDs you can read aloud

IDs follow ISO 6346, the real freight-container format: owner code SHP, category U, six-digit serial, and a boxed check digit computed the real way.

The kernel, made visible

The inspector shows the real mechanics: which namespaces are on, the cgroup path, memory.max, host PID versus PID 1. It's the systems work you're building, shown as UI.
