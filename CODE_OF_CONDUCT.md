# Code of conduct

Shipyard follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1: be welcoming and respectful, criticize ideas rather than people, and assume
good faith. Harassment, personal attacks and publishing someone's private information
are not tolerated, in issues, pull requests, discussions or anywhere the project is
represented.

## Reporting

Report a problem privately to the maintainer through the contact on their
[GitHub profile](https://github.com/Zena4L). Reports are read promptly and kept
confidential. For a security vulnerability, use the route in [SECURITY.md](SECURITY.md)
instead.

## Enforcement

The maintainer may remove, edit or reject comments, commits, code and issues that don't
follow this code, and may ban a contributor, temporarily or for good, following the
Covenant's enforcement guidelines.
